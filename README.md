# 📦 Sistema de Estoque

Aplicação desenvolvida em **Java** para gerenciamento básico de produtos e controle de estoque.

O projeto foi desenvolvido como um projeto de estudo para praticar conceitos de programação, organização de código e desenvolvimento de aplicações utilizando Java.

## 🚀 Funcionalidades

- Cadastro inicial de produtos
- Visualização dos produtos cadastrados
- Adição de produtos ao estoque
- Remoção de produtos do estoque
- Alteração do valor dos produtos
- Consulta das informações dos produtos
- Registro das operações realizadas no sistema

## 🛠️ Tecnologias utilizadas

- Java
- Java Swing
- IntelliJ IDEA
- Git
- GitHub

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/jeanalvesz/SistemaEstoque.git
```

2. Abra o projeto no **IntelliJ IDEA**.

3. Configure uma versão do **JDK** compatível com o projeto.

4. Execute a classe:

```text
SistemaEstoque.java
```
